
# Fasiha Nadeem - CV Portfolio Website

## About the Project
This is my personal CV and portfolio website created to present my education, technical skills, projects, courses, and contact information.

The website uses a clean design with a forest green, sage green, and ivory color theme.

## Features
- Personal introduction and profile avatar
- Education details
- Technical skills and strengths
- Projects showcase
- Courses and certifications
- Languages
- Contact information
- Responsive layout
- Automatically updated copyright year using JavaScript

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Project Structure

## How to Run
1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` using Live Server or your browser.
